## 1.1 요구사항 기능 명세 표

| 요구사항 ID | 구분 | 기능명 | 담당자 | 우선순위 | 상세 내용 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| REQ-USER-01 | 회원 | 회원가입 | 용쌤 | 1순위 | 이메일, 비밀번호, 닉네임, 프로필 이미지를 입력받아 member 및 member_detail 테이블에 저장 |
| REQ-USER-02 | 회원 | 로그인/토큰 발급 | 용쌤 | 1순위 | 이메일/비밀번호 검증 후 JWT Access Token 및 Refresh Token 발급 |
| REQ-USER-03 | 회원 | 토큰 갱신(RTR) | 용쌤 | 1순위 | 만료된 Access Token 요청 시 Refresh Token 검증을 거쳐 새 토큰 쌍 재발급 |
| REQ-USER-04 | 회원 | 내 프로필 조회 | 용쌤 | 1순위 | JWT 토큰 기반 인증 사용자(AuthenticationPrincipal)의 회원 정보 및 상세 정보 조회 |
| REQ-USER-05 | 회원 | 프로필 정보 수정 | 용쌤 | 2순위 | 닉네임, 프로필 이미지 URL, 한 줄 소개, 주소 정보 갱신 |
| REQ-POST-01 | 피드 | 피드 목록 조회 | 하루 | 1순위 | 전체 피드 게시글 목록 페이징(Pageable) 조회, 작성자 정보 및 좋아요 수, 댓글 수 포함 |
| REQ-POST-02 | 피드 | 피드 등록 | 하루 | 1순위 | 로그인 회원 본문 입력, AWS S3 이미지 업로드, 해시태그 파싱 후 post 및 post_hashtag에 저장 |
| REQ-POST-03 | 피드 | 피드 상세 조회 | 하루 | 1순위 | 피드 단건 정보, 작성자 프로필, 해시태그 목록, 댓글 목록 일괄 조회 |
| REQ-POST-04 | 피드 | 피드 수정/삭제 | 하루 | 1순위 | 작성자 본인 확인 후 피드 내용 및 해시태그 수정, 피드 삭제 (CASCADE 댓글/좋아요 정리) |
| REQ-POST-05 | 피드 | 해시태그 검색 | 하루 | 2순위 | 특정 해시태그(#여행 등) 클릭 또는 키워드 입력 시 해당 태그가 포함된 피드 목록 필터링 |
| REQ-INTER-01 | 인터랙션 | 댓글 작성/삭제 | 나무 | 1순위 | 피드 상세에서 댓글 작성 및 저장, 작성자 본인 댓글 삭제 |
| REQ-INTER-02 | 인터랙션 | 좋아요 토글 | 나무 | 1순위 | 피드 좋아요 클릭 시 post_like 등록/삭제 토글 및 post 테이블 like_count 증감 동기화 |
| REQ-INTER-03 | 인터랙션 | 북마크 저장/취소 | 나무 | 2순위 | 관심 피드를 bookmark 테이블에 저장/취소 토글 처리 |
| REQ-INTER-04 | 인터랙션 | 내 북마크 목록 | 나무 | 2순위 | 마이페이지에서 본인이 북마크한 피드 카드 목록만 모아보기 |
| REQ-PAY-01 | 결제/구독 | 결제 준비/사전검증 | 용쌤 | 1순위 | 클라이언트 결제 요청 전 서버에 결제 고유번호(merchant_uid) 및 결제 예정 금액 등록 |
| REQ-PAY-02 | 결제/구독 | 단건 결제 사후검증 | 용쌤 | 1순위 | 결제창 SDK 결제 완료 후 결제 승인 고유번호(imp_uid)로 PG사 결제 검증 API를 호출하여 실제 결제 금액 일치 검증 |
| REQ-PAY-03 | 결제/구독 | VIP 정기구독 빌링키 발급 | 용쌤 | 2순위 | 카드 정보를 통해 정기 결제 빌링키(customer_uid)를 발급받아 subscription 테이블에 등록 |
| REQ-PAY-04 | 결제/구독 | 정기 결제 스케줄러 | 용쌤 | 2순위 | 매월 구독 결제일에 빌링키를 이용해 PG사 정기 결제 재승인 API 호출 및 회원 VIP 등급 유지 |
| REQ-PAY-05 | 결제/구독 | 결제 웹훅(Webhook) 처리 | 용쌤 | 2순위 | 비동기 결제 승인, 가상계좌 입금, 결제 취소 통보를 서버에서 수신하여 결제 상태 동기화 |
