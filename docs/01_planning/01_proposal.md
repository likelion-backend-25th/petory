## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
- 반려인들이 반려동물의 일상을 사진·태그·BGM과 함께 공유하고, 건강·훈련·병원 등 실질적인 정보를 교류하며, 유기동물 보호에도 참여할 수 있는 반려동물 전문 SNS 플랫폼(Petory) 구축.
- 백엔드와 프론트엔드가 분리된 현대적인 웹 아키텍처 환경에서 Spring Boot 기반의 REST API 백엔드와 React 기반의 클라이언트 애플리케이션 간 비동기 데이터 통신 체계 확립.
- API 연동을 통해 간식쏘기(일회성 후원), 펫 클럽(크리에이터 정기 구독), 유기동물 모금 등 사회적 가치를 동시에 실현.

### 1.1.2 서비스 주요 특징
- JWT 기반 로그인/인증 토큰 자동 갱신 보안 적용.
- 사진·태그·BGM 업로드 기반의 반려동물 피드, Q&A 게시판, 분실동물 찾기 등 다양한 콘텐츠 제공.
- 좋아요, 댓글, 북마크, 팔로우/팔로워, 알림 등 SNS 핵심 소셜 기능 제공.
- 간식쏘기(후원), 펫 클럽(유료 구독), 등 결제 기능 연동.
- AWS(EC2, S3) 기반 배포.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 인증 관리 기능
- 회원가입 (이메일, 비밀번호, 닉네임, 프로필 이미지, 동물이름, 종류, 생일, 성별)
- 자체 로그인 및 소셜 로그인 (카카오, 구글) 지원 (OAuth 2.0).
- JWT 기반 토큰 발급 (Access Token, Refresh Token).
- 만료 토큰 자동 갱신
- 팔로워 수 기준 구독 가격 상한선이 늘어나는 인증회원 승격.
- 내 프로필 조회 및 마이페이지 정보 수정.

### 1.2.2 SNS 피드 및 게시판 관리 기능
- 피드 작성 (사진, 태그, BGM 업로드 포함).
- 피드 목록 조회 (페이징, 키워드 검색, 필터링).
- 피드 상세 조회, 수정, 삭제 (본인 작성 피드만 제어).
- Q&A 게시판 (정보 공유).
- 분실동물 찾기 게시판

### 1.2.3 소셜 상호작용 기능
- 좋아요, 댓글 작성/삭제,조회수, 북마크 저장 및 취소.
- 팔로우/팔로워 기능.
- 알림 (팔로우한 펫 생일, 좋아요, 댓글, 팔로워 알림,후원 알림).

### 1.2.4 결제 관리 기능
- 간식쏘기 (반려동물에게 일회성 후원 결제).
- 펫 클럽 정기 구독 (크리에이터가 가격 설정, 카드 자동 결제).
- 빌링키 발급 및 월 자동 결제 실행.
- 결제 금액 위변조 방지를 위한 사전/사후 검증.
- 결제 취소, 환불 처리 및 결제 내역 조회.

### 1.2.5 1:1 채팅 관리 기능
- 회원 프로필·분실동물 등에서 1:1 채팅방 생성.
- 채팅방 목록 조회 (상대 프로필, 마지막 메시지).
- 텍스트 메시지 전송 및 대화 이력 조회.
- 채팅방 나가기
