## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
- 반려인들이 반려동물의 소중한 일상을 사진·태그·BGM과 함께 공유하고, 건강·훈련·병원 등 실질적인 정보를 교류하며, 위치 기반 분실동물 찾기 및 크리에이터 후원까지 하나의 플랫폼에서 해결할 수 있는 오직 반려동물만을 위한 전용 SNS 웹 서비스(Petory) 구축.
- 백엔드와 프론트엔드가 분리된 아키텍처 환경에서 Spring Boot 기반의 REST API 백엔드와 React 기반의 클라이언트 애플리케이션 간 비동기 데이터 통신 체계 확립.

### 1.1.2 서비스 주요 특징
- JWT 기반 로그인/인증 토큰 자동 갱신 보안 적용.
- 사진·태그·BGM 업로드 기반의 반려동물 피드, Q&A 게시판, 분실동물 찾기 등 다양한 콘텐츠 제공.
- 좋아요, 댓글, 북마크, 팔로우/팔로워, 알림 등 SNS 핵심 소셜 기능 제공.
- 간식쏘기(후원), 펫 클럽(유료 구독), 등 결제 기능 연동.
- AWS(EC2, S3) 및 Netlify 기반 배포 및 CI/CD 환경 구축.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 인증 관리 기능
- 회원가입 (이메일, 비밀번호, 닉네임, 프로필 이미지, 동물이름, 종류, 생일, 성별)
- 자체 로그인 및 소셜 로그인 (카카오, 구글) 지원 (OAuth 2.0).
- JWT 기반 토큰 발급 (Access Token, Refresh Token).
- 만료 토큰 자동 갱신
- 팔로워 수 기준 구독 가격 상한선이 늘어나는 인증회원 승격.
- 내 프로필 조회 및 마이페이지 정보 수정.

### 1.2.2 SNS 피드 및 게시판 관리 기능
- 피드 작성 (사진, 태그, BGM 업로드 포함).
- 피드 목록 조회 (페이징, 키워드 검색, 필터링).
- 피드 상세 조회, 수정, 삭제 (본인 작성 피드만 제어).
- Q&A 게시판 (정보 공유).

### 1.2.3 소셜 상호작용 기능
- 좋아요, 댓글 작성/삭제,조회수, 북마크 저장 및 취소.
- 팔로우/팔로워 기능.
- 알림 (팔로우한 펫 생일, 좋아요, 댓글, 팔로워 알림,후원 알림).

### 1.2.4 결제 관리 기능
- 간식쏘기 (반려동물에게 일회성 후원 결제).
- 펫 클럽 정기 구독 (크리에이터가 가격 설정, 카드 자동 결제).
- 빌링키 발급 및 월 자동 결제 실행.
- 결제 금액 위변조 방지를 위한 사전/사후 검증.
- 결제 취소, 환불 처리 및 결제 내역 조회.

### 1.2.5 1:1 채팅 관리 기능
- 회원 프로필·분실동물 등에서 1:1 채팅방 생성.
- 채팅방 목록 조회 (상대 프로필, 마지막 메시지).
- 텍스트 메시지 전송 및 대화 이력 조회.
- 채팅방 나가기


### 1.2.6 분실동물 및 제보 관리 기능
- 실종 신고 작성/수정/삭제 (동물 정보, 사진, 특징 및 진행 상태 관리).
- 지도 API 연동을 통한 실종 장소 주소 검색 및 위도·경도 좌표 마커 등록.
- 목격 제보 작성/수정/삭제 (목격 위치 지도 마커, 목격 일시, 현장 사진 및 임시 보호 여부 작성).
- 신고자-제보자 간 1:1 채팅

### 1.3.2 역할 분담 원칙
모든 팀원은 특정 기술 레이어에 치우치지 않고, 각자 맡은 도메인에 대해 React UI(바이브 코딩)부터 Spring Boot REST API 및 DB 처리까지 수직 슬라이스 형태로 구현.

### 1.3.3 팀원별 도메인 담당 정의
#### 1) 김남규 (PM)
- 총괄 역할: 프로젝트 일정 및 범위 관리
- 담당 도메인: 소셜 상호작용(좋아요, 댓글, 북마크, 알림) 및 Spring Scheduler를 활용한 시스템 개발.

#### 2) 김병호 (PL)
- 총괄 역할: 기술 표준 수립, Spring Security 및 JWT 인증/인가 체계 구축.
- 담당 도메인: 자체 및 소셜 로그인(OAuth 2.0), 마이페이지, 1:1 채팅 관리, 회원/게시글/결제 관리자 시스템 개발.

#### 3) 유동훈 (팀원)
- 총괄 역할:AWS(EC2, S3) 및 프론트엔드(Netlify) 인프라 CI/CD 배포 파이프라인 총괄, 발표 수행.
- 담당 도메인: 메인 피드 CRUD, 결제 시스템 개발
#### 4) 임민교 (팀원)
- 담당 도메인: Q&A 게시판(카테고리 필터링), 지도 API 기반 분실동물 실종 신고/목격 제보 등록 및 위치 마커 조회 시스템 개발.
