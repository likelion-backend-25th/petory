## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
- 백엔드와 프론트엔드가 분리된 현대적인 웹 아키텍처 환경에서 대규모 피드 탐색, 해시태그 기반 관심사 공유, 실시간 소셜 상호작용을 지원하는 SNS 플랫폼(사자그램) 구축.
- Spring Boot 기반의 REST API 백엔드와 React 기반의 클라이언트 애플리케이션 간 비동기 데이터 통신 체계 확립.
- 전자결제 대행(PG) API 연동을 통해 일반 사용자와 유료 창작자 간의 VIP 정기 구독 결제 및 멤버십 비즈니스 모델(BM) 적용.

### 1.1.2 서비스 주요 특징
- JWT(JSON Web Token) 기반 무상태 인증 및 RTR(Refresh Token Rotation) 재발급 보안 체계 적용.
- 이미지 업로드 및 해시태그 연동을 통한 멀티미디어 피드 공유.
- 댓글, 좋아요 토글, 북마크 보관함을 통한 사용자 간 양방향 소셜 인터랙션 제공.
- 결제/구독 연동 기반의 월간 VIP 멤버십 정기 구독 및 유료 전용 콘텐츠 잠금 해제.
- AWS 인프라(EC2, S3, CloudFront) 기반의 고성능 분리 배포 환경 구축.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 인증 관리 기능
- 회원가입 (이메일, 비밀번호, 닉네임, 프로필 이미지).
- 회원 상세 정보 수직 분할 저장 (한 줄 소개, 주소, 마케팅 수신 동의).
- JWT 기반 로그인 및 토큰 발급 (Access Token, Refresh Token).
- 만료 토큰 자동 갱신 (RTR 전략 적용).
- 내 프로필 조회 및 마이페이지 정보 수정.

### 1.2.2 SNS 피드 및 해시태그 관리 기능
- 피드 게시글 목록 조회 (페이징, 키워드 검색, 해시태그 필터링).
- 신규 피드 작성 (본문 작성, AWS S3 이미지 업로드, 다중 해시태그 자동 추출 및 저장).
- 피드 상세 조회, 수정, 삭제 (본인 작성 피드 제어).
- VIP 멤버십 전용 유료 피드 표시 및 접근 권한 분기.

### 1.2.3 소셜 상호작용 기능
- 피드 댓글 작성, 목록 조회, 삭제.
- 피드 좋아요(Like) 토글 및 실시간 좋아요 수 증감.
- 관심 피드 북마크(스크랩) 저장, 취소 및 보관함 목록 조회.

### 1.2.4 결제 및 VIP 구독 관리 기능
- 브라우저 결제창 SDK 연동을 통한 결제창 호출 및 단건 결제.
- 서버 사이드 결제 사전/사후 검증 API를 통한 결제 금액 위변조 방지.
- 월간 VIP 멤버십 정기 구독을 위한 빌링키(Billing Key) 발급 및 저장.
- 정기 결제 스케줄러(Spring Batch / Scheduled) 기반 월 자동 결제 실행.
- 결제 취소, 환불 및 결제 웹훅(Webhook) 비동기 수신 처리.

## 1.3 팀 구성 및 도메인별 역할 분담

### 1.3.1 팀명 및 역할 분담표 (팀명: 사자그램)

| 이름 | 직책 | 담당 도메인 | 세부 구현 내용 |
| :--- | :--- | :--- | :--- |
| 용쌤 | PM | 회원 및 결제 관리 | 프로젝트 총괄 관리, JWT 인증/인가, 결제 검증 및 VIP 정기 구독 연동 |
| 하루 | PL | 피드 및 해시태그 | 기술 리드, 피드 CRUD, AWS S3 이미지 파이프라인, 해시태그 매핑 및 검색 |
| 나무 | 팀원 | 소셜 상호작용 | 댓글 CRUD, 좋아요 토글 동시성 제어, 북마크 보관함 관리 |

### 1.3.2 역할 분담 원칙
모든 팀원은 특정 기술 레이어에 치우치지 않고, 각자 맡은 도메인에 대해 React UI(바이브 코딩)부터 Spring Boot REST API 및 DB 처리까지 수직 슬라이스 형태로 구현.

### 1.3.3 팀원별 도메인 담당 정의
#### 1) 용쌤 (PM)
- 총괄 역할: 프로젝트 일정 및 범위 관리, Spring Security 및 JWT 체계 수립, AWS 인프라(EC2, S3, CloudFront) 배포 총괄.
- 담당 도메인: 회원 가입/로그인, 토큰 갱신, 결제 검증 API 및 VIP 구독 스케줄러.

#### 2) 하루 (PL)
- 총괄 역할: 기술 표준 수립, 공통 아키텍처 및 미디어 파이프라인 설계.
- 담당 도메인: 피드 게시글 목록/상세/등록/수정/삭제, AWS S3 이미지 저장소 연동, 해시태그 테이블 연동 및 다중 조건 검색.

#### 3) 나무 (팀원)
- 담당 도메인: 댓글 작성/삭제, 게시글 좋아요 토글 및 복합 유니크 제약 관리, 북마크 저장 및 마이페이지 연동.
